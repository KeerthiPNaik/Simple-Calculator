# Simple Calculator 

A basic web-based calculator built using **HTML**, **CSS**, and **JavaScript**.  
It can perform standard arithmetic operations like addition, subtraction, multiplication, division and modulus.

## Features

- Responsive design
- Supports basic operations:
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
  - Modulus (%)
- Clear (`AC`) and Delete (`DEL`) buttons
